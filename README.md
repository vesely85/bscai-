## How to present

| Action | Control |
| --- | --- |
| Next / previous slide | `→` `Space` / `←` |
| Jump to slide 1–9 | number keys `1`–`9` |
| Story-map overview | `O` |
| Zoom | scroll / pinch / `+` `−` |
| Pan | click-drag / one-finger drag |
| Dive into nearest slide | double-click |
| Fullscreen | `F` |

There's also an on-screen dock (prev/next, zoom, overview, fullscreen) and a clickable dot strip.

## The story (13 slides)

Cover → the customer's question → past / today / future → why paper stopped winning → **the four-pillar framework** (a hub you *zoom into*) → each pillar (Configurability · UI ease · Customer access · Integration) → two proof case studies → "from recording to reasoning" (AI next) → close.

The four-pillar framework acts as a spatial hub; each pillar's detail slide is a satellite the camera flies and zooms into — the signature zoom-navigation moment.
